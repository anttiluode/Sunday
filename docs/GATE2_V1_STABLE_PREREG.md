# Gate 2 v1 prereg — stable abstract-graph attacker

Date: 2026-08-23

Gate 2 v0 was invalidated because the explicit-Euler cubic probe overflowed on some degree+strength-matched rewires. See `docs/GATE2_V0_INVALID.md`.

## Question

Does Euclidean locality act as a useful inductive/topological constraint for Gate 1's learned pair relation, even though the exact graph is sufficient for execution once constructed?

## Arms

Unchanged from v0:

- **GEO** — radial 3-D overlap graph.
- **GRAPH-SAME** — exact GEO base matrix with coordinates erased. This tests coordinate necessity after graph construction.
- **REWIRE-DS** — repeated double-edge swaps preserve exact unweighted degree sequence; symmetric diagonal scaling matches every node's initial weighted degree/strength to relative error `< 1e-8`; locality is considered destroyed if at least half of rewired edges are longer than GEO's overlap cutoff in the original coordinates.

## Stable nonlinear probe

Learning itself remains unchanged.

For the frozen-morphology nonlinear response only, each original response step `dt=0.035` is divided into exactly:

```text
substeps = 8
h = dt / 8
```

The external drive is held constant across those substeps. Total simulated time and total drive duration remain unchanged. Soma AUC is integrated at substep resolution.

The same substepped probe is used for GEO and REWIRE-DS.

A confirmation run is invalid if any arm still produces non-finite state/AUC/interaction values.

## Frozen held-out range

```text
seed_start = 300000
seed_count = 12
```

The consumed v0 range `280000..280011` must not be reused as confirmation.

## Frozen thresholds

```text
GEO overlap positive fraction           >= 0.90 for each pair
GEO interaction positive fraction       >= 0.90 for each pair
GEO mean overlap separation             >= 0.04
GEO mean interaction separation         >= 0.0015

GRAPH-SAME max mass/metric difference   < 1e-12

REWIRE exact degree sequence             true for every seed
REWIRE connected                         true for every seed
REWIRE initial strength rel error        < 1e-8
REWIRE long-edge fraction                >= 0.50 for every seed
all nonlinear values finite             true

GEO / REWIRE mean |overlap| ratio       >= 3.0
GEO / REWIRE mean |interaction| ratio   >= 2.0
```

Ratios use the mean absolute REWIRE effect in the denominator so sign cancellations cannot make the attacker look artificially weak.

## Interpretation

If v1 passes, the safe statement is only:

> Current Sunday dynamics reduce to a graph after construction, so 3-D coordinates are not execution-time necessities. However, under matched node degree and initial node strength, a graph generated by Euclidean locality supports a substantially stronger/more reproducible learned relational effect than a non-geometric rewire in this instrument.

This would make 3-D **an inductive constraint / graph generator**, not a new computational substance.

If v1 fails, demote the 3-D claim and keep Gate 1 as an abstract adaptive-graph phenomenon.
