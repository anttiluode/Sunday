# Sunday audit — reservoir and symmetry nulls

Date: 2026-08-23

Sunday reached Gate 12 with a coherent but increasingly reservoir-like object. Before adding another mechanism, this audit asks two deliberately destructive questions.

## Audit A — fixed-reservoir / trained-readout null

Gate 9 established that, on the controlled rank-7 relation-program span, finite learned outputs are almost linear in the registered relation vector `q`.

Gate 10 supplies a dormant one-step feature map

```text
x(q) = q W
```

where `W` is the 15-pair x 256 one-step structural write matrix measured from uniform dormant mass.

The audit asks whether `x(q)` already preserves the complete rank-7 relation span. If it does, then a fixed dormant substrate plus an externally trained linear readout can represent any linear `q -> y` map on this controlled span. In that case Gate 9's relation-space operator is not, by itself, evidence for a new computing primitive.

Fresh audit range:

```text
520000..520005
```

Report:

- `rank(QW)`;
- minimum leave-one-code-out rank of `QW`;
- leave-one-code-out reconstruction of the unseen `q` from `x=qW` using a linear readout trained on the other 15 controlled codes;
- condition ratio of the dormant write map restricted to the rank-7 relation span.

Important distinction: this null is allowed to store learned information in an external readout. It therefore attacks Sunday's **computation/representation novelty**, not the separate fact that Sunday can persist training history inside structural mass after fast state is reset.

## Audit B — six-terminal symmetry / spectral null

Gate 9 found that about 98% of the empirical relation operator energy lies in three stable input modes. The six physical terminals, however, are placed on an exact ring. Before calling the three modes a new material algebra, ask how much is already forced or strongly suggested by ordinary ring symmetry.

The controlled relation span has dimension seven. Under one-step rotation of the six-terminal ring, decompose it into real cyclic harmonic sectors.

The exact sector dimensions are measured from the registered `Q`; no learned output enters the decomposition.

Exploratory dormant work identified one specific geometry-only 3-D candidate before the fresh full-training range:

```text
nearest-neighbor edge-orbit k=2 harmonic copy (2-D)
+
k=3 parity harmonic (1-D)
```

Fresh full-training audit range:

```text
522000..522003
```

For each substrate, fit the same all-direction minimum-norm Gate-9 finite operator only for mode analysis, then compare its top-three input singular subspace with:

1. the fixed geometry-only 3-D candidate above;
2. the broader `k=2 plus k=3` symmetry sector.

Also report how much of the learned top-three subspace lies in `k=1`, `k=2`, and `k=3` sectors.

Interpretation is intentionally graded:

- if the fixed 3-D geometry-only candidate nearly equals the learned top-three subspace, demote the three-mode mystery to ring symmetry;
- if only the broader harmonic sector matches, symmetry explains the coarse sector but not the exact compression/orientation;
- if neither matches, the preferred modes require more substrate-specific dynamics/topology.

## No rescue rules

These are audits, not new capability gates. Their job is to reduce claims.

Do not respond to a strong null by adding phase, growth, images, extra state, or another learned controller. Preserve whatever distinction actually survives.
